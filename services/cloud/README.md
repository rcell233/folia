# Folia Cloud

Folia Cloud is the backend service shipped by the Folia self-hosted
collaborative workspace distribution.

This directory is based on a pinned AppFlowy Cloud revision and retains its
upstream history, license, and copyright notices. Folia adds deployment,
compatibility, and product patches around that baseline. See the repository
root [`README.md`](../../README.md), [`docs/BASELINE.md`](../../docs/BASELINE.md),
and [`NOTICE`](../../NOTICE) for the supported deployment process, provenance,
and attribution.
